# Adakole's Web Development Portfolio & Coursework

A collection of responsive web pages, UI components, and interactive JavaScript applications built from scratch using semantic HTML5, modern CSS3, and vanilla JavaScript.

## Live Portfolio & Deployed Projects

* **Main Portfolio Homepage:** [https://vercel.app](https://vercel.app)
* **Interactive To-Do List (`todo.html`):** [https://vercel.app/todo.html](https://vercel.app/todo.html)
* **JS Grid Calculator (`calculator.html`):** [https://vercel.app/calculator.html](https://vercel.app/calculator.html)
* **Product Landing Page (`landing.html`):** [https://vercel.app/landing.html](https://vercel.app/landing.html)
* **Interactive Quiz App (`quiz.html`):** [https://vercel.app/quiz.html](https://vercel.app/quiz.html)
* **Image Gallery Carousel (`gallery.html`):** [https://vercel.app/gallery.html](https://vercel.app/gallery.html)

## Features & Technologies Used

* **HTML5:** Semantic structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) and accessible form labels.
* **CSS3:** Custom CSS variables, Google Fonts typography, Flexbox layouts, CSS Grid matrices, responsive mobile media queries, and a persistent Dark Mode theme.
* **JavaScript (ES6+):** DOM manipulation, `localStorage` data persistence, array methods (`.map()`, `.filter()`, `.reduce()`), keyboard event listeners, and client-side form validation.
* **Git & Deployment:** Feature-branch Pull Request workflows on GitHub with continuous deployment via Vercel.

## How to Run Locally

1. Clone this repository to your computer:
   ```bash
   git clone https://github.com/adakolee124-prog/web-homework.git
   ```
2. Open the `web-homework` folder in VS Code.
3. Open `index.html` in any modern web browser (or use the VS Code Live Server extension).
